# Pending Inbox Format

Recommended project path: `docs/PENDING.md`.

```markdown
# Pending

## P-YYYY-NNN — <concise observation>

- Status: untriaged / triaged / scheduled / blocking / absorbed / dismissed
- Source: <Change, Phase, review finding, or evidence path>
- Evidence:
- Why deferred from the source scope:
- Potential consequence:
- Blocking trigger:
- Suggested destination:
- Owner:
- Related ADR / Roadmap / Change:
- Created / last triaged:
```

The discoverer records an observation, not an approved solution. Update an existing matching item rather than creating duplicates.
